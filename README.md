# VANITY — the Vanity Role-Playing Game (Foundry VTT system)

A generic d6 RPG where ego is a resource and the universe keeps score. Pool = Attribute + Knack +
situation; 5–6 = a Success; fail a roll showing two or more 1s and you **Stumble**, banking a Bane
of Karma. No hit points — Grit. Vanity, Karma and Glory drive play.

**Install (Foundry v13+):** Setup → Game Systems → Install System → Manifest URL:
`https://raw.githubusercontent.com/slaguru666/Vanity/main/system.json`

Recommended module: **Dice So Nice!** (the peacock dice + red Bane dice; the system runs fine without it).
Optional companion: **Mapwright** for full procedural maps.

This repo is the published system only. Development, the rulebook drafts, play aids and the
*Vain Crown* world live in the private VRPG repo.
